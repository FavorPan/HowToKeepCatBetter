## 这本书怎么用

每条建议回答两个问题：花掉什么（钱、时间、精力），换回什么（猫的重病和死亡风险下降、主人省下多少钱和时间）。

四条标准：

- 按「性价比」排序，不按类别。「成本接近零、收益大」的条目放最前面。
- 每条标注证据等级 A / B / C。
- 只引原始文献：期刊论文（附 DOI 或 PubMed 链接）、兽医权威机构指南原文（WSAVA、AAFP、ISFM）、官方机构报告。不引自媒体和带货内容。
- 全文免费开源（CC BY 4.0），可复制、可修改、可再发布，注明出处即可。

## 收益算成三种账，不互相换算

- **猫的健康**：寿命、重病发生率、死亡风险。
- **主人的钱**：花出去的钱、省下来的钱、避免的医疗支出。
- **主人的时间**：每天占用的和省下的时间精力。

一条建议主要换回哪样，就按哪样算账。每节内的条目按性价比从高到低排。

## 读懂数字（术语表）

- **证据等级 A**：有可量化证据，来自荟萃分析、大型队列或随机对照试验，能给出具体数字。
- **证据等级 B**：有研究支撑但难以量化，或证据来自小样本、单一研究。
- **证据等级 C**：兽医共识或权威指南的定性建议，没有直接文献。
- **荟萃分析**：把多项同类研究合在一起算总结果的统计方法。
- **队列**：只是一群人（或一群猫）长期跟踪记录、没有分组对照。
- **HR / RR / OR**：风险比、相对风险、比值比，都是「一组比另一组高或低多少」的倍数。
