标签和证据等级是什么意思
证据 A / B / C
A 有可量化证据，来自荟萃分析、大型队列或随机对照试验；B 有研究支撑但难以量化，或来自小样本、单一研究；C 兽医共识或权威指南的定性建议。
钱 0 / 少 / 多
0 不花钱或省钱；少 几十到几百元或每月几十元内；多 上千元或长期显著支出。
时间 少 / 中 / 多
少 一次几分钟内或顺手；中 一次性数小时或每周小时级；多 每天持续占用。
毅力 否 / 些 / 是
否 做一次就完；些 改一个习惯或忍一点不适；是 长期对抗惯性。
口径
